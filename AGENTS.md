Назначение документа
--------------------

Документ содержит постоянные правила ИИ-агента для всех классов задач.


Ресурсы
-------

### Навыки ИИ-агента

Проектные навыки ИИ-агента находятся в каталоге `skills/<skill_name>/SKILL.md` и соответствуют стандарту Agent Skills.

Каждый навык содержит YAML-заголовок с полями `name` и `description`, определяющими его идентификатор и назначение.

Агент должен определять применимые навыки по их описаниям и следовать инструкциям соответствующих `SKILL.md`.

### Проектная документация

- введение: `README.md`
- техзадание: `docs/SPECIFICATION.md`
- архитектура: `docs/ARCHITECTURE.md`
- реализация: `docs/IMPLEMENTATION.md` (необязательный)


Правила
-------

### Разделитель файловых путей

При записи файловых путей в документации и исходном коде проекта в качестве разделителя каталогов использовать прямую косую черту (`/`).
