Назначение документа
--------------------

Документ содержит основные проектные инструкции ИИ-агента.


Специализированные навыки
-------------------------

При общении с пользователем в чате использовать навык `skills/interacting/SKILL.md`.

При планировании и изменении архитектуры проекта использовать навык `skills/architecting/SKILL.md`.

При создании, проверке и редактировании проектной документации использовать навык `skills/documenting/SKILL.md`.

При создании, проверке и редактировании программного кода использовать навык `skills/coding/SKILL.md`.
