Назначение документа
--------------------

Документ задает единую терминологию для инструкций ИИ-агента.


Формат определений
------------------

Стиль словарный, справочный. Рекомендуемая структура определения:

```text
Термин - родовое понятие + отличительный признак + назначение (при необходимости).
```


Терминология
------------

**Агент** или **ИИ-агент** - ИИ-система, выполняющая задачи пользователя в соответствии с установленными инструкциями. При возможной неоднозначности используется полное обозначение "ИИ-агент".

**Документ контентный** - Markdown-документ (`*.md`), не содержащий заголовков первого уровня (H1), предназначенный для включения в другой документ или расширения его содержимого.

ПРИМЕЧАНИЕ: Markdown-документов (`*.md`) без заголовка первого уровня (H1), предназначенных для самостоятельного использования, быть не должно. Для самостоятельных документов без H1 следует использовать формат `*.txt`.

**Документ межпроектный** - документ, предназначенный для повторного использования в разных проектах независимо от принадлежности к конкретному проекту.

**Документ структурный** - Markdown-документ (`*.md`), содержащий хотя бы один заголовок первого уровня (H1).

ПРИМЕЧАНИЕ: Структурные документы могут ссылаться друг на друга, но не могут быть включены друг в друга.

**Документа ревизия** (Revision) - состояние документа, зафиксированное в определённом коммите Git-репозитория.

**Документа редакция** (Edition) - редакторская версия межпроектного документа, обозначаемая меткой в виде даты-времени в формате ISO 8601 с указанием времени UTC (`YYYY-MM-DDTHH:mm:ssZ`). Метка редакции обновляется вручную по решению редактора, однократно перед коммитом. Временная метка позволяет определить хронологический порядок редакций, но не гарантирует включения изменений из других проектов. При параллельной модификации документов необходимо сравнивать их содержимое.

**Задача** - поручение пользователя, направленное на достижение определённого результата и выполняемое посредством одного или нескольких действий, включая при необходимости правки.

**Навык** (Skill) - каталог с обязательным файлом `SKILL.md`, содержащим метаданные в формате YAML frontmatter и инструкции в формате Markdown для выполнения ИИ-агентом специализированных задач. Может включать дополнительные инструкции, скрипты и вспомогательные ресурсы.

**Пользователь** - человек или другой ИИ-агент, формулирующий задачи для данного ИИ-агента.

**Правка** - отдельное, логически завершённое изменение содержимого файла, выполняемое в рамках задачи.

**Файл текстовый** (Plain Text File) - файл, содержащий текстовые данные в определённой символьной кодировке (ASCII, UTF-8, UTF-16 и др.), доступные для чтения и редактирования обычными текстовыми редакторами.
