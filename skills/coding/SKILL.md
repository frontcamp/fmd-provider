Назначение документа
--------------------

Документ содержит общие инструкции по работе с программным кодом и механизм маршрутизации специализированных инструкций для конкретных языков программирования.


Языковые инструкции
-------------------

Поверх общих инструкций применять специализированные языковые инструкции, находящиеся в каталоге: `references/languages/<lang_id>.md`. Получи список файлов в этом каталоге и по идентификатору подключай только те файлы с инструкциями, которые нужны.
