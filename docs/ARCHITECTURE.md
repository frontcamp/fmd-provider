
Архитектура проекта
===================

Проект состоит из трёх подсистем:
1) архив биржевых данных
2) реестр ISIN
3) провайдер данных


Архив биржевых данных
---------------------

Локализация в проекте: каталог `data/`, в котором две ветки:
1) `sources/` - буфер исходных данных со скриптами нормализации
2) `normalized/` - архив нормализованных биржевых данных

Задача этой подсистемы: сбор, нормализация и архивация биржевых данных.
Сбор выполняется из внешних источников вручную. Нормализация автоматизирована.


Реестр ISIN
-----------

Локализация в проекте: каталог `libs/isinreg/`.
Задача подсистемы: предоставление названий финансовых инструментов по кодам ISIN. Для наполнения и обновления реестра используются данные о бессрочных финансовых инструментах, коды ISIN которых встречаются в архиве нормализованных биржевых данных. Эти условия позволяют резко сократить объем реестра (с 17 миллионов до примерно 24 тысяч).


Провайдер данных
----------------

Локализация в проекте: `fmd-provider.py`
Задачи подсистемы: 1) предоставление информации об архиве; 2) предоставление данных инструмента за период в указанном формате.
