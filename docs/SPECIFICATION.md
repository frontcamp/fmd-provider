Назначение провайдера данных
----------------------------

FMD Provider является программным компонентом комплекса FMD-Trader. Состав проекта и задачи его подсистем описаны в docs/ARCHITECTURE.md. Задачи скрипта провайдера (fmd-provider.py):

1. Информация о содержании архива

    - список идентификаторов торговых площадок (MIC), контейнеров и локальных наборов данных, представленых в архиве
    - название набора данных по идентификатору
    - информация о покрытии данных указанной торговой площадки (годы,дни/периоды)
    - список ISIN-кодов инструментов для указанной торговой площадки (опц. за период)
    - название инструмента по ISIN-коду
    - мин/макс цен инструмента для указанной торговой площадки (опц. за период)

2. Предоставление данных архива

    - выбор результирующего формата: файл CSV или MailDir папка-поток
    - для MailDir количество записей в одном файле
    - фильтрация по торговой площадке/инструменту
    - фильтрация по дате/времени
    - группировка в свечи длительностью кратной 1 секунде
    - минимаксная нормализация цены в заданный диапазон
    - задержка генерации для имитации потока реальных биржевых данных
