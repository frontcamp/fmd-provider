Назначение провайдера данных
----------------------------

FMD Provider является программным компонентом комплекса FMD-Trader. Состав проекта и задачи его подсистем описаны в docs/ARCHITECTURE.md. Задачи скрипта провайдера (fmd-provider.py):

1. Предоставление сводных данных по архиву

    - данные каких бирж представлены в архиве (их MIC/Title)
    - информация о содержимом данных по указанной бирже (дни/периоды)
    - информация по инструментам указанной биржи (опционально, с уточнением периода)
    - информация о мин/макс значениях цен по указанному инструменту за период
    - информация по инструменту (название, мин/макс цен) за период

2. Предоставление данных

    - выбор результирующего формата: файл CSV или MailDir папка-поток
    - фильтрация по бирже/инструменту
    - фильтрация по дате/времени
    - задержка генерации для имитации потока реальных биржевых данных
    - минимаксная нормализация цены в указанный диапазон
