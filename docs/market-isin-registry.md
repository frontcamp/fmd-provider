
Реестр ISIN
===========

Назначение документа - техническое задание на организацию и реализацию реестра ISIN.

ISIN - International Securities Identification Number, международный идентификационный номер финансового инструмента.


Предпосылки ведения реестра
---------------------------

При работе с графическим интерфейсом (проект fmd-explorer) потребуется выводить человекопонятные названия финансовых инструментов. Для этого нужен реестр соответствий: ISIN (код) / Title (название) / Short (короткий заголовок FISN).
Поскольку архив нормализованных биржевых данных формируется и хранится в данном проекте (fmd-provider), реестр ISIN логично реализовать в виде модуля этого проекта.

Почему нужен именно локальный реестр:

1. Автономность - чтобы с проектом можно было работать оффлайн.
2. Скорость доступа - если понадобится обработать большие объемы, локальный реестр при соответствующей организации будет работать быстрее сетевого REST API и, как следствие, скорость его работы не будет зависесть от скорости сетевого соединения.
3. Стабильность и надежность - онлайн решение может быть временно недоступно или вообще оказаться отключенным перманентно.


Источники ISIN данных
---------------------

В качестве источников данных реестра могут использоваться:
1) реестр финансовых инструментов FIRDS Европейского управления по ценным бумагам и рынкам (ESMA), содержащий ISIN и названия финансовых инструментов;
2) рыночные данные бирж (которые предоставляют подобную информацию), в этом случае можно проверять и дополнять реестр ISIN каждый раз при нормализации рыночных данных;
3) рыночные бюллетни ISIN данных, где это предусмотрено и имеются соответствующие данные, например, в формате CSV;
4) REST API запросы к бесплатным онлайн-реестрам для получения недостающих позиций в локальном реестре.


Особенности ISIN данных
-----------------------

Эти данные являются относительно статичными. Сильная динамика ожидается только в момент первичного наполнения реестра. Изменения в реестре (добавляение новых, обновление или удаление существующих ключей) будут возникать крайне редко.
То есть, реестр должен быть оптимизирован под две частотные операции: добавление и поиск по ISIN (получение title или short).


Особенности реализации
----------------------

Реестр реализован в виде пакета libs/isinreg/ с реализацией класса ISINRegistry в модуле libs/isinreg/_registry.py, в атрибутах которого хранится состояние реестра внутри текущего процесса и методов класса для работы с реестром. Под состоянием имеется в виду: путь к файлу реестра (SQLite), соединение с базой данных, и т.п.

В реестре сохраняются записи вида: `<isin, title, short>`
isin - код ISIN (первичный ключ)
title - название финансового инструмента
short - короткий заголовок FISN по ISO 18774


Примеры использовани реестра
----------------------------

```python
from libs.isinreg import ISINRegistry

ISINRegistry.get_isin_title('LU3086265710')
ISINRegistry.get_isin_short('US91324PFJ66')
```
